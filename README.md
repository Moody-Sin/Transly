# Transly

> 基于 Rust 的高性能跨平台桌面翻译与浏览器整页沉浸式翻译工具。

[![standard-readme compliant](https://img.shields.io/badge/readme%20style-standard-brightgreen.svg?style=flat-square)](https://github.com/RichardLitt/standard-readme)

Transly 是一款基于 Rust 与 Tauri 2 构建的跨平台桌面翻译软件，拥有极低内存开销和毫秒级响应。同时配备深度协作的浏览器插件，主打“整页翻译仅译文”的极简沉浸式阅读体验。

## 背景

许多传统翻译软件常伴随高内存占用、臃肿功能（不必要的社交、生词本背诵推送）以及破坏网页原有排版的双语排版。Transly 聚焦于核心翻译诉求：
1. **轻量极速**：Rust 核心逻辑，极简系统资源占用。
2. **纯粹沉浸**：浏览器插件主打“仅显示目标语言译文”，原地替换 DOM 文本节点，完全保真原有样式排版。
3. **安全透明**：所有密钥托管于系统原生凭据管理器，明文不落盘，前端与外部网页零接触 API Key。

## 架构

```
┌─────────────────────────────────────────┐
│  前端 (React + TS + Tailwind)           │
│  - 只负责 UI 与交互                       │
│  - 不直接发起翻译请求                     │
└───────────────┬─────────────────────────┘
                │ Tauri IPC（tauri-specta 强类型调用）
┌───────────────▼─────────────────────────┐
│  src-tauri（平台适配层）                  │
│  - Tauri command 薄封装                   │
│  - 平台集成：快捷键/剪贴板/截图/OCR/托盘   │
│  - 本地 HTTP 服务（供浏览器插件调用）      │
└───────────────┬─────────────────────────┘
                │ 纯 Rust 调用
┌───────────────▼─────────────────────────┐
│  transly-core（核心逻辑，无 Tauri 依赖）  │
│  - 翻译与 OCR 引擎抽象与实现              │
│  - 缓存 / 语言检测 / 术语库               │
│  - 可被桌面端、CLI、WASM 复用             │
└─────────────────────────────────────────┘
```

### 源码开发构建

需要满足以下开发环境要求：
- [Node.js](https://nodejs.org/) (>= 22.6) 与 [pnpm](https://pnpm.io/)
- [Rust](https://www.rust-lang.org/) (edition 2021+)
- 目标平台对应的 C/C++ 构建工具链（如 Windows 上的 MSVC，Linux 上的 build-essential 和 WebKitGTK 依赖等）

克隆代码并安装依赖：

```sh
git clone https://github.com/Moody-Sin/Transly.git
cd transly
pnpm install
```

## 用法

### 1. 桌面端使用
启动桌面端开发模式或安装包：

```sh
pnpm tauri dev
```

- **快捷悬浮翻译**：选中文本按下 `Alt+Shift+D`，自动唤起轻量悬浮迷你窗并即时翻译；支持图钉（Pin）永久置顶与窗口自由拖拽。
- **划词原地翻译替换**：选中文本按下 `Alt+Shift+R`（支持自定义热键），自动将当前选区文本原地翻译并直接覆盖替换，全流程自动保护系统原剪贴板内容；支持自定义首选引擎，遇到故障即时弹出 Toast 告警。
- **框选截图翻译**：按下 `Alt+Shift+S`（支持自定义热键），或点击主窗口底栏「截图翻译」按钮、托盘菜单「截图翻译」。屏幕冻结为覆盖窗后拖拽框选任意区域，自动 OCR 识别并按**原坐标叠加译文**（保排版），可一键「还原原文」；支持在覆盖窗内直接切换引擎与目标语言即时重译、复制全部译文、把结果发送到主窗口精修重译。
- **文档与字幕文件翻译**：支持拖拽或选择 `.txt`、`.md`（Markdown）、`.srt`（字幕）、`.json`（本地化字典）与 `.html`（网页）文件。独家纯 Rust 保真解析引擎：严格锁定 SRT 序号与时间轴、免翻保护 Markdown YAML Frontmatter、多行代码块与数学公式，无损保护 JSON 键名与 HTML 标签结构；通过单事务批量缓存与切批流水线高效翻译，支持实时进度感知、双栏预览及一键导出为对应格式文件。
- **离线智能对转**：集成纯 Rust 高性能 Unicode 脚本语言检测器，微秒级识别源语言。在输入中文时自动对转为英文，输入外文时自动对转为中文，彻底免除手动切换目标语言下拉框。
- **代码与公式保真**：纯 Rust 智能提取 Markdown 多行代码块与行内代码并进行 Unicode 专有括线占位保护，翻译完成后精准还原缩进与代码结构。
- **全离线混合翻译引擎与本地模型扩展**：内置纯 Rust 高频开发词汇与日常短语 Aho-Corasick 双向自动机（带西文词边界保护与中英文标点智能对转，断网即时可用）；支持一键预设 Ollama（`localhost:11434`）、LM Studio（`localhost:1234`）、llama.cpp（`localhost:8080`）等本地 OpenAI 兼容服务，接入真实本地大模型，亦可自定义任意本地端点，完全离线隐私翻译。
- **LLM 专业风格预设与本地离线模型 (Ollama)**：支持通用直译、学术技术、文学润色与商务公文四类 Prompt 风格预设；支持一键预置直连本地 Ollama（`http://localhost:11434/v1`），完全离线隐私翻译。
- **多策略网络代理体系**：支持默认自动（环境代理优先 -> 自动嗅探 Windows 注册表系统代理 -> 直连回退）、系统代理、手动代理（HTTP/HTTPS/SOCKS5）与强制直连；设置修改后即时热重载生效。
- **翻译历史全量流式导出**：支持倒序浏览最近翻译、实时模糊检索过滤，以及一键流式导出为 CSV（防 Excel 乱码与公式注入）或 JSON 文件。
- **系统原生 TTS 语音朗读**：基于 Web Speech API 规范化发音代码，零体积、零依赖提供原文与译文原生语音朗读。
- **全局深色模式 (Dark Mode)**：支持浅色模式、深色模式与跟随系统三态切换。
- **快捷键智能录制器**：可视化录制快捷键，支持修饰键捕获与冲突检测。
- **剪贴板监听**：在主界面开启“剪贴板监听”，复制文本即可自动翻译。
- **独立术语库**：基于 Aho-Corasick 流式自动机单趟高效匹配，支持「区分大小写」开关与 CJK/西文智能词边界保护。
- **应用内自动更新**：设置中心内可手动检查 GitHub Releases 新版本，一键下载、签名校验并安装重启；更新包由流水线使用 minisign 私钥签名，客户端以内置公钥验签，拒绝被篡改的更新。
- **缓存与隐私**：可在设置中开启或关闭“持久化翻译缓存”。关闭时系统将自动清空磁盘翻译历史，且不影响术语库。

### 2. 浏览器插件使用与配对
1. 打开 Chrome / Edge 扩展管理页面（`chrome://extensions`），开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择 `extension/dist`（或解压后的插件包目录）。
3. **一键自动安全配对（推荐）**：打开浏览器插件 Popup，点击【一键配对桌面端】；桌面端主窗口自动拉起并弹出配对授权卡片，点击【允许配对】即可自动握手写入 Token，连接状态变为“● 已连接且配对有效”。（亦支持在桌面端设置中复制 Token 手动粘贴配对）。
4. **整页沉浸式翻译**：点击“翻译此网页 (仅译文)”，正文原地无损替换为译文；或切换至“双语对照”模式；点击“还原原文”瞬间恢复。支持勾选「为此站点记住自动翻译」实现站点级自动化。
5. **视口感知优先切批 (Viewport-First)**：首屏可视文本优先切批外呼，离屏段落保序排队，数百毫秒内呈现当前屏幕译文。
6. **开放式 Shadow DOM 穿透与富文本段落保真**：完整支持 Web Components 内部节点提取；段落内嵌入链接、加粗等行内标签整句翻译保真，杜绝语序颠倒破版。
7. **划词微型悬浮图标与气泡**：在任意网页选中一段文本，光标右上角自动浮现微型 Transly 图标，点击直接展开译文气泡；亦可右键选择「Transly 翻译选中文本」。气泡渲染于封闭式 Shadow DOM 中，支持一键复制，`Esc` 或点击外部关闭。
8. **悬浮查看原文 Tooltip**：原地仅译文替换后，鼠标悬停于译文段落上方，自动浮现 Shadow DOM 浮层展示原始文本。
9. **网页输入框原地翻译替换助手**：在网页任意 `input` 或 `textarea` 中输入文本后，按下 `Alt+Shift+R` 或右键点击「Transly 原地翻译替换」，自动将当前选区或输入框正文原地替换为目标译文；深度支持 React / Vue 受控表单状态同步，附带微型浮动完成反馈。
10. **精细化站点规则配置**：点击 Popup 中的「站点规则设置」，可为当前域名单独配置排除 CSS 选择器（如 `.code, pre` 保护指定元素免受整页翻译篡改）、站点专属目标语言绑定，以及输入框助手禁用开关。
11. **Token 轮换**：若在桌面端点击“重新生成扩展配对 Token”，旧 Token 将即时失效（401 拦截），在扩展重新一键配对即可恢复。

### 3. 已知限制与注意事项
- **商业引擎失败不再自动降级 (0.4.0 起)**：已彻底移除跨引擎自动降级机制。此前 DeepL / OpenAI / DeepSeek 报错时会静默切换至 Google 网页翻译，现在**不再切换**，界面直接呈现所选引擎的真实错误（如未配置 API Key、额度耗尽、网络不可达）。
  若您依赖旧版「失败自动兜底」行为，请任选其一应对：① 为所选引擎配置有效 API Key 并保持网络可达；② 在主窗口或悬浮窗顶栏的下拉框中手动切换引擎；③ 选择新支持的**离线引擎**（纯本地、零外呼，断网可用）。
- **复杂富文本编辑器**：为保障页面编辑安全，Transly 默认不对 `contenteditable`、富文本代码编辑器（如 Monaco / CodeMirror）及包含 `.notranslate` 属性的节点进行强行替换。
- **扩展按需注入**：扩展不再向所有网站常驻注入脚本，仅在您点击「翻译此网页」或右键菜单「Transly 翻译选中文本」时向当前标签页注入，因此无需全站宿主权限；浏览器内部页（`chrome://`）等受限页面无法注入。
- **截图与 OCR 的平台能力**：全流程内存零落盘，绝不写入临时文件。
  - **Windows**：GDI `BitBlt` 捕获 + 系统原生 `Windows.Media.Ocr`，无需任何额外系统依赖。
  - **macOS**：`CGDisplayCreateImage` 捕获 + 系统原生 Vision OCR。**首次使用需在「系统设置 → 隐私与安全性 → 屏幕录制」中授权，授权后需重启应用**。
  - **Linux**：仅支持 **X11**（xcb 捕获 + 外呼 `tesseract`）。Wayland 会话下框选截图不可用（系统级截图 API 需落临时文件，且 compositor 不认窗口置顶），界面会直接禁用按钮并给出说明；此时仍可使用「识别剪贴板图片」。若未安装 tesseract，会返回可执行的安装命令（`sudo apt-get install -y tesseract-ocr tesseract-ocr-chi-sim`）。
  - **受保护内容无法截取**：Netflix 等启用内容保护（DRM / `WDA_EXCLUDEFROMCAPTURE`）的窗口由操作系统在合成层排除，**任何用户态方案都拿不到画面**，界面会给出明确提示。
  - **只覆盖光标所在显示器**：跨显示器框选未支持（需拼接多张不同 DPR 的图，收益低而错误率高）。
- **剪贴板图片 OCR**：主输入框底栏「识别剪贴板图片」入口，三平台均可用（Windows/macOS 走系统原生 OCR，Linux 走 tesseract）。
- **外部 API 差异**：DeepL、OpenAI 及 DeepSeek 需在设置中配置有效 API Key（安全托管于系统凭据管理器中，绝不上传第三方服务器）。
