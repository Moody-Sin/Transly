# Transly v0.2.0 Phase 3 (桌面翻译工作流一致性) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让主窗口输入框、划词（Alt+Shift+D）、剪贴板监听、浮窗四类桌面入口共享同一套任务状态机（Idle/Queued/Running/Succeeded/PartiallyFailed/Failed/Cancelled）、同一套结构化错误分类与可重试判定、同一套取消（代际丢弃）与缓存策略。

**Architecture:**
- `crates/transly-core/src/task.rs`（新建）：定义 `TaskState`（7 状态枚举，serde `snake_case`）、`TaskError { kind: ErrorKind, message: String, retryable: bool }`、`TaskOutcome { state, text, engine, error }`，以及纯函数 `classify_error(&Error) -> TaskError`（错误类别→可重试判定唯一来源）。核心层不持有任务实例，状态值只作为跨层传递的数据。
- `src-tauri/src/commands/mod.rs`：`translate` 返回值由 `Result<String, String>` 升级为 `Result<TranslateOutcome, String>`（`TranslateOutcome = { text, engine, cached, error: Option<TaskError> }`），结构化错误不再退化为裸字符串。**失败仍走 `Err` 通道的错误（引擎异常）保留为 `Err`，但 IPC 错误体改为 JSON 序列化的 `TranslateErrorDto { kind, message, retryable }`**，使前端可按 `kind` 分类而不解析后端字符串。
- `src/main.rs`：`float-translate` 事件负载由 `String` 升级为 `FloatRequest { text, source: 'selection' | 'clipboard', request_id }`；剪贴板轮询加去重与最小长度门槛；划词模拟复制期间抑制剪贴板监听自发触发。
- `src/`（前端）：新建 `src/task/useTaskRunner.ts` 承载代际号 + 状态机 + 取消 + 重试，`src/task/taskState.ts` 为纯函数状态机（可被 `node:test` 直接验证），`App.tsx` 的主窗口与 `#float` 浮窗共用同一 hook，UI 通过 `ErrorKind` 映射 i18n 提示，不匹配后端错误字符串。

**Tech Stack:** Rust 1.x（tokio / serde / thiserror / tauri-specta 2.0.0-rc.25 / specta 2.0.0-rc.25）、TypeScript 5.7 strict（React 19、Tailwind、lucide-react）、Node 24 原生 `node:test` + `--experimental-strip-types`（零新依赖）。

**Spec:** `docs/superpowers/specs/2026-07-17-v0.2.0-design.md`（阶段三：四类桌面入口一致行为；引擎与术语配置体验）

## Global Constraints

- 严格分层：`crates/transly-core` 禁止引入 Tauri 依赖；`src-tauri` 仅平台适配与 command 薄封装；`src` 前端不直接发起翻译网络请求。
- 取消语义采用**前端代际号丢弃**（不引入 Rust 侧 `JoinHandle` 注册表）：每次新操作 `generation += 1`，所有在途回调在应用结果前校验代际，不匹配则丢弃。已在途的网络请求不 abort（引擎层 `reqwest::Client` 无取消通道，强行 abort 需改动核心层，阶段三不做）。
- 取消 ≠ 还原：桌面单文本入口无"原文还原"概念；取消仅停止后续动作并丢弃在途结果，已应用的译文保持。
- 缓存策略四入口共享：全部经 `commands::translate` → 同一 `CacheController` generation 门禁与 `cache.set(..., res.actual_engine())` 真实引擎键；缓存禁用时不得写回。
- 敏感信息：日志与错误消息禁止包含 API Key、Bearer Token、完整原文、译文。
- 质量门禁（提交前必须全绿）：
  `cargo fmt --check` + `cargo clippy --workspace -- -D warnings` + `cargo test --workspace` + `pnpm run lint` + `pnpm run build` + `pnpm run test:task`（本计划新增）
- `.gitignore` 只增不删。
- 提交消息遵循 Conventional Commits，简体中文。

## Review Focus

以下五类是规格隐含但无任何测试覆盖、最可能咬人的行为，每条在下文对应 Task 的步骤中带上测试：

- **迟到结果污染**：用户在第 1 代请求在途时点了取消或发起了新输入，第 1 代结果回来后**绝不能**覆盖第 2 代的译文或错误提示（`useTaskRunner` 提交结果前的代际校验）。
- **剪贴板与划词互相污染**：Alt+Shift+D 的模拟 Ctrl+C 会写入系统剪贴板，若剪贴板监听已开启，必须抑制这次自触发的监听翻译，否则同一段文字被翻译两次、浮窗被弹两次（`main.rs` 抑制标志 + `source` 区分）。
- **可重试判定准确**：`Input`（空文本/超长/非法语言码）与 `Auth`（未配置密钥）错误**绝不能**显示"重试"按钮——重试 100 次结果相同；`Network`/`Timeout`/`Engine` 才显示重试（`classify_error` 单测）。
- **浮窗失焦自动隐藏与错误展示冲突**：浮窗失焦即 `hide()`，但错误/重试按钮必须可见才能点击；错误态下浮窗不得在用户点"重试"前自动收起（`App.tsx` 浮窗焦点保持）。
- **缓存禁用期间的在途写回**：翻译进行中用户关闭缓存，本次翻译结果不得写入 SQLite（复用 `CacheController::set_if_current` 既有语义，前端不得绕过）。

```rust
use serde::{Deserialize, Serialize};

use crate::error::{Error, ErrorKind};

/// 跨入口共享的任务状态（仅数据；任务实例与生命周期由宿主或入口适配层持有）
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum TaskState {
    Idle,
    Queued,
    Running,
    Succeeded,
    PartiallyFailed,
    Failed,
    Cancelled,
}

impl TaskState {
    /// 结束状态：不再接受旧结果回流
    pub fn is_terminal(self) -> bool {
        matches!(
            self,
            TaskState::Succeeded | TaskState::PartiallyFailed | TaskState::Failed | TaskState::Cancelled
        )
    }

    /// 活动状态：存在在途请求
    pub fn is_active(self) -> bool {
        matches!(self, TaskState::Queued | TaskState::Running)
    }
}

/// 结构化任务错误：kind 供 UI 分类，retryable 供 UI 决定是否显示重试
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct TaskError {
    pub kind: ErrorKind,
    pub message: String,
    pub retryable: bool,
}

/// 任务终态快照
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct TaskOutcome {
    pub state: TaskState,
    pub text: Option<String>,
    pub engine: Option<String>,
    pub error: Option<TaskError>,
}

/// 错误类别 → 可重试判定的唯一来源。
/// 判定原则：只有"重试可能得到不同结果"的瞬时故障才可重试；
/// Input（文本非法）、Auth（缺密钥）、Cancelled（用户主动）重试必然同样失败。
pub fn classify_error(err: &Error) -> TaskError {
    let kind = err.kind();
    let retryable = matches!(kind, ErrorKind::Network | ErrorKind::Timeout | ErrorKind::Engine | ErrorKind::Config);
    TaskError {
        kind,
        message: err.to_string(),
        retryable,
    }
}
```

在 `crates/transly-core/src/lib.rs` 增加 `pub mod task;` 与 `pub use task::{classify_error, TaskError, TaskOutcome, TaskState};`。

**注意 1（必须照做）**：`tauri-specta` 的 `Result<T, E>` 会把 `Err(E)` 序列化为拒绝的 Promise，`E` 必须实现 `serde::Serialize`。错误类型不能是 `String`（那会让前端只能解析字符串），故改为 `TranslateErrorDto`。

**注意 2（`ErrorKind` 必现阻塞）**：`TranslateErrorDto` 含 `ErrorKind` 字段，而 `ErrorKind` 当前**未派生** `specta::Type`，直接写 DTO 会编译失败。`specta 2.0.0-rc.25` 已在 workspace `Cargo.lock` 中（随 `tauri-specta` 引入），故在 core 加一行依赖不带来额外构建成本：

- `crates/transly-core/Cargo.toml` 的 `[dependencies]` 增加：`specta = { version = "=2.0.0-rc.25", features = ["derive"] }`
- `crates/transly-core/src/error.rs` 中 `ErrorKind` 的派生改为：
  ```rust
  #[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, specta::Type)]
  #[serde(rename_all = "snake_case")]
  pub enum ErrorKind { /* 变体不变 */ }
  ```
  specta 遵循已有的 `#[serde(rename_all = "snake_case")]`，生成 TS 为 snake_case 字面量联合，与前端 `ErrorKind` 一致。

```rust
#[derive(serde::Serialize, serde::Deserialize, specta::Type)]
pub struct TranslateOutcomeDto {
    pub text: String,
    pub engine: String,
    pub cached: bool,
    pub detected_source_lang: Option<String>,
}

#[derive(serde::Serialize, serde::Deserialize, specta::Type)]
pub struct TranslateErrorDto {
    pub kind: ErrorKind,
    pub message: String,
    pub retryable: bool,
}

impl TranslateErrorDto {
    pub fn from_error(err: &Error) -> Self {
        let t = classify_error(err);
        Self { kind: t.kind, message: t.message, retryable: t.retryable }
    }
}

impl From<Error> for TranslateErrorDto {
    fn from(err: Error) -> Self { Self::from_error(&err) }
}
```

`translate` 函数体改动（保持缓存门禁与术语逻辑不变，只改类型）：

```rust
pub async fn translate(
    text: String,
    source_lang: Option<String>,
    target_lang: String,
    engine_name: Option<String>,
    cache: tauri::State<'_, Arc<TranslationCache>>,
    pool: tauri::State<'_, Arc<EnginePool>>,
    glossary: tauri::State<'_, Arc<RwLock<Glossary>>>,
    cache_controller: tauri::State<'_, Arc<crate::cache_controller::CacheController>>,
) -> Result<TranslateOutcomeDto, TranslateErrorDto> {
    let sl = source_lang.unwrap_or_else(|| "auto".to_string());

    transly_core::validate_translation_input(&text, &sl, &target_lang)
        .map_err(|e| TranslateErrorDto { kind: ErrorKind::Input, message: e.to_string(), retryable: false })?;

    if let Some(ref eng) = engine_name {
        if !transly_core::validate_engine_id(eng) {
            return Err(TranslateErrorDto {
                kind: ErrorKind::Input,
                message: format!("不支持或未知的翻译引擎: {eng}"),
                retryable: false,
            });
        }
    }

    let active_engine = if let Some(ref name) = engine_name {
        pool.get_engine(name).await
    } else {
        pool.default_engine()
    };
    let engine_id = active_engine.id();

    let (cache_enabled, start_gen) = cache_controller.snapshot();

    if cache_enabled {
        if let Ok(Some(cached_text)) = cache.get(&text, &sl, &target_lang, engine_id) {
            let g = glossary.read().await;
            let applied = g.apply(&cached_text);
            return Ok(TranslateOutcomeDto {
                text: applied,
                engine: engine_id.to_string(),
                cached: true,
                detected_source_lang: None,
            });
        }
    }
```

```ts
// 避免前后端枚举各自维护导致漂移。`export type` 在编译/类型剥离时完全擦除，

import type { ErrorKind } from '../bindings'
export type { ErrorKind }

export type TaskState =
  | 'idle' | 'queued' | 'running' | 'succeeded' | 'partially_failed' | 'failed' | 'cancelled'

export interface TaskError {
  kind: ErrorKind
  message: string
  retryable: boolean
}

const TERMINAL: ReadonlySet<TaskState> = new Set<TaskState>([
  'succeeded', 'partially_failed', 'failed', 'cancelled',
])

export function isTerminal(state: TaskState): boolean {
  return TERMINAL.has(state)
}

/** 仅失败态且错误本身可重试时提供重试入口；后端已在 classify_error 判定过一次 */
export function canRetry(state: TaskState, error: TaskError | null): boolean {
  return state === 'failed' && error?.retryable === true
}

export function nextState(
  current: TaskState,
  event: 'submit' | 'resolve' | 'reject' | 'cancel' | 'reset',
): TaskState {
  switch (event) {
    case 'submit':
      return 'running'
    case 'resolve':
      return 'succeeded'
    case 'reject':
      return 'failed'
    case 'cancel':
      return current === 'running' || current === 'queued' || current === 'idle'
        ? 'cancelled'
        : current
    case 'reset':
      return 'idle'
  }
}
```

```ts
import { useCallback, useEffect, useRef, useState } from 'react'
import { listen } from '@tauri-apps/api/event'
import { commands } from '../bindings'
import {
  canRetry, nextState,
  type TaskError, type TaskState,
} from './taskState'
import { applyIfCurrent } from './generation'

export { applyIfCurrent }

export interface RunnerSnapshot {
  state: TaskState
  text: string
  engine: string | null
  error: TaskError | null
  source: 'input' | 'selection' | 'clipboard' | null
  sourceText: string
}

export interface TaskRunner {
  snapshot: RunnerSnapshot
  run: (text: string, opts?: { source?: RunnerSnapshot['source']; debounceMs?: number }) => void
  cancel: () => void
  retry: () => void
  reset: () => void
}

interface FloatRequest {
  text: string
  source: 'selection' | 'clipboard'
  request_id: number
}

export function useTaskRunner(engine: string, targetLang: string): TaskRunner {
  const [snapshot, setSnapshot] = useState<RunnerSnapshot>({
    state: 'idle', text: '', engine: null, error: null, source: null, sourceText: '',
  })

  const genRef = useRef(0)
  const lastRunRef = useRef<{ text: string; source: RunnerSnapshot['source'] } | null>(null)
  const debounceRef = useRef<ReturnType<typeof setTimeout> | null>(null)
  const seenFloatIdsRef = useRef<Set<number>>(new Set())

  const engineRef = useRef(engine)
  const langRef = useRef(targetLang)
  engineRef.current = engine
  langRef.current = targetLang

  const execute = useCallback(async (text: string, source: RunnerSnapshot['source']) => {
    const gen = ++genRef.current
    lastRunRef.current = { text, source }
    setSnapshot((s) => ({ ...s, state: nextState(s.state, 'submit'), error: null }))

    const res = await commands.translate(text, 'auto', langRef.current, engineRef.current)
    if (gen !== genRef.current) return

    if (res.status === 'ok') {
      setSnapshot({
        state: nextState('running', 'resolve'),
        text: res.data.text,
        engine: res.data.engine,
        error: null,
        source,
        sourceText: text,
      })
    } else {
      setSnapshot({
        state: nextState('running', 'reject'),
        text: '',
        engine: null,
        error: { kind: res.error.kind, message: res.error.message, retryable: res.error.retryable },
        source,
        sourceText: text,
      })
    }
  }, [])

  const run = useCallback((text: string, opts?: { source?: RunnerSnapshot['source']; debounceMs?: number }) => {
    if (!text.trim()) return
    if (debounceRef.current) { clearTimeout(debounceRef.current); debounceRef.current = null }
    const source = opts?.source ?? 'input'
    const delay = opts?.debounceMs ?? 0
    if (delay > 0) {
      debounceRef.current = setTimeout(() => { void execute(text, source) }, delay)
    } else {
      void execute(text, source)
    }
  }, [execute])

  const cancel = useCallback(() => {
    if (debounceRef.current) { clearTimeout(debounceRef.current); debounceRef.current = null }
    genRef.current += 1
    setSnapshot((s) => (s.state === 'running' || s.state === 'queued'
      ? { ...s, state: nextState(s.state, 'cancel') }
      : s))
  }, [])

  const retry = useCallback(() => {
    const last = lastRunRef.current
    if (!last) return
    setSnapshot((s) => (canRetry(s.state, s.error) ? { ...s } : s))
    void execute(last.text, last.source)
  }, [execute])

  const reset = useCallback(() => {
    if (debounceRef.current) { clearTimeout(debounceRef.current); debounceRef.current = null }
    genRef.current += 1
    lastRunRef.current = null
    setSnapshot({ state: 'idle', text: '', engine: null, error: null, source: null, sourceText: '' })
  }, [])

  // 订阅划词 / 剪贴板事件：按 request_id 去重，同一段文本只翻译一次
  useEffect(() => {
    let unlisten: (() => void) | undefined
    listen<FloatRequest>('float-translate', (event) => {
      const payload = event.payload
      if (!payload?.text?.trim()) return
      if (seenFloatIdsRef.current.has(payload.request_id)) return
      seenFloatIdsRef.current.add(payload.request_id)
      run(payload.text, { source: payload.source })
    }).then((fn) => { unlisten = fn }).catch(() => {})
    return () => { if (unlisten) unlisten() }
  }, [run])

  // 组件卸载时作废全部在途代际
  useEffect(() => () => { genRef.current += 1 }, [])

  return { snapshot, run, cancel, retry, reset }
}
```
