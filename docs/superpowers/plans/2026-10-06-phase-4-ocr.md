# 阶段四：剪贴板图片 OCR 与翻译闭环实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 实现 Windows 原生 `Windows.Media.Ocr` 剪贴板图片提取、尺寸下采样、多语言去重轮询识别与即时翻译闭环，提供零落盘内存安全保证与专属 OCR 结构化错误反馈。

**Architecture:** 
`transly-core` 定义专属 `OcrErrorKind` / `OcrErrorDto` 契约；`src-tauri` 在 `spawn_blocking` 中使用 `tauri-plugin-clipboard-manager` 读取剪贴板图片，经 RGBA $\to$ BGRA8 转码与等比下采样后调用 `Windows.Media.Ocr`（非 Windows 平台存根返回明确未支持）；IPC 命令 `ocr_clipboard_image` 将识别文本输入前端主输入框并以 `debounceMs: 0` 立即接入现有统一任务状态机。

**Tech Stack:** Rust (edition 2021), Tauri 2, `windows` 0.62 (`Media_Ocr`, `Graphics_Imaging`, `Storage_Streams`, `Win32_System_WinRT`, `Globalization`), `image` 0.25, React 19, TypeScript, Tailwind CSS, tauri-specta.

**Spec:** `docs/superpowers/specs/2026-10-06-phase-4-ocr-design.md`

## Global Constraints

- 核心库 `crates/transly-core` 保持纯 Rust，禁止引入 Tauri 依赖。
- 所有 WinRT 调用与 `clipboard.read_image()` 必须封装在 `tauri::async_runtime::spawn_blocking` 作用域内，主线程严禁阻塞。
- WinRT 线程初始化必须成对调用 `RoInitialize(RO_INIT_MULTITHREADED)` 与 RAII `RoUninitialize`。
- 图片生命周期严格内存闭环，严禁临时文件落盘，前端不留存图片 Base64 或 Blob 数据。
- 候选语言轮询必须保持顺序去重，候选集仅包含 `targetLang === 'zh-CN' ? 'en-US' : 'system'`、`'system'`、`'en-US'`。
- 非 Windows 操作系统编译存根实现，恒返回 `OcrErrorKind::UnsupportedPlatform`，杜绝假成功，确保 CI 跨平台编译绿灯。

## Review Focus

1. **剪贴板无图片或只有文本**：调用返回 `OcrErrorKind::NoImage`，前端展示明确错误条目，不触发翻译流程。
2. **大尺寸高清截图（长边 > 2600px）**：触发等比平滑下采样至 Windows OCR 上限之内，避免被系统底层直接拒绝。
3. **首选与备选引擎重合（如英文版 Windows 翻译到 zh-CN）**：去重后仅执行一次英文识别，不产生重复无用轮询。
4. **截图中无文字或无法辨识**：所有候选引擎均返回空串时，返回 `OcrErrorKind::EmptyText`，禁止向翻译引擎发起空请求。
5. **Ubuntu CI / 非 Windows 编译运行**：`cargo test --workspace` 编译通过，调用返回 `OcrErrorKind::UnsupportedPlatform`。

```rust
#[serde(rename_all = "snake_case")]
pub enum OcrErrorKind {
    NoImage,
    NoLanguagePack,
    EmptyText,
    DimensionExceeded,
    UnsupportedPlatform,
    Internal,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, specta::Type)]
pub struct OcrErrorDto {
    pub kind: OcrErrorKind,
    pub message: String,
}

impl OcrErrorDto {
    pub fn new(kind: OcrErrorKind, message: impl Into<String>) -> Self {
        Self {
            kind,
            message: message.into(),
        }
    }

    pub fn no_image() -> Self {
        Self::new(OcrErrorKind::NoImage, "剪贴板中无有效图片数据")
    }

    pub fn empty_text() -> Self {
        Self::new(OcrErrorKind::EmptyText, "未能从图片中识别到有效文字")
    }

    pub fn no_language_pack() -> Self {
        Self::new(OcrErrorKind::NoLanguagePack, "系统未安装对应 OCR 语言包组件")
    }

    pub fn unsupported_platform() -> Self {
        Self::new(OcrErrorKind::UnsupportedPlatform, "当前操作系统暂未支持平台原生 OCR")
    }

    pub fn internal(msg: impl Into<String>) -> Self {
        Self::new(OcrErrorKind::Internal, msg)
    }
}
```

```rust
/// 构建去重候选识别语言列表
pub fn build_candidate_languages(target_lang: &str) -> Vec<&'static str> {
    let primary = if target_lang.trim() == "zh-CN" {
        "en-US"
    } else {
        "system"
    };

    let mut list = Vec::with_capacity(2);
    for cand in [primary, "system", "en-US"] {
        if !list.contains(&cand) {
            list.push(cand);
        }
    }
    list
}

/// 将 RGBA8 像素切片转换为 Windows SoftwareBitmap 所需的 BGRA8 字节序
pub fn rgba_to_bgra(rgba: &[u8]) -> Vec<u8> {
    let mut bgra = rgba.to_vec();
    for chunk in bgra.chunks_exact_mut(4) {
        chunk.swap(0, 2);
    }
    bgra
}

/// 等比下采样计算：保证宽高均不大于 max_dim
pub fn clamp_dimensions(w: u32, h: u32, max_dim: u32) -> (u32, u32) {
    let max_side = w.max(h);
    if max_side <= max_dim || max_side == 0 {
        return (w, h);
    }
    let scale = max_dim as f64 / max_side as f64;
    let nw = ((w as f64 * scale).round() as u32).max(1);
    let nh = ((h as f64 * scale).round() as u32).max(1);
    (nw, nh)
}
```

```rust
use tauri_plugin_clipboard_manager::ClipboardExt;
use transly_core::{OcrErrorDto, OcrErrorKind};

#[cfg(not(target_os = "windows"))]
pub async fn recognize_clipboard_image(
    _app: &tauri::AppHandle,
    _target_lang: &str,
) -> Result<String, OcrErrorDto> {
    Err(OcrErrorDto::unsupported_platform())
}

#[cfg(target_os = "windows")]
struct ComGuard;

#[cfg(target_os = "windows")]
impl ComGuard {
    fn new() -> Self {
        unsafe {
            let _ = windows::Win32::System::WinRT::RoInitialize(
                windows::Win32::System::WinRT::RO_INIT_MULTITHREADED,
            );
        }
        Self
    }
}

#[cfg(target_os = "windows")]
impl Drop for ComGuard {
    fn drop(&mut self) {
        unsafe {
            windows::Win32::System::WinRT::RoUninitialize();
        }
    }
}

#[cfg(target_os = "windows")]
pub async fn recognize_clipboard_image(
    app: &tauri::AppHandle,
    target_lang: &str,
) -> Result<String, OcrErrorDto> {
    let app_handle = app.clone();
    let target_lang = target_lang.to_string();

    tauri::async_runtime::spawn_blocking(move || {
        let _guard = ComGuard::new();

        // 1. 读取剪贴板图片（避免在主线程阻塞）
        let img = match app_handle.clipboard().read_image() {
            Ok(im) => im,
            Err(e) => {
                let msg = e.to_string();
                if msg.contains("no image") || msg.contains("empty") {
                    return Err(OcrErrorDto::no_image());
                }
                return Err(OcrErrorDto::new(OcrErrorKind::NoImage, msg));
            }
        };

        let width = img.width();
        let height = img.height();
        if width == 0 || height == 0 {
            return Err(OcrErrorDto::no_image());
        }

        // 2. 检查并等比下采样尺寸
        let max_dim = windows::Media::Ocr::OcrEngine::MaxImageDimension().unwrap_or(2600);
        let (nw, nh) = clamp_dimensions(width, height, max_dim);
        
        let rgba_bytes = if nw != width || nh != height {
            let dyn_img = image::RgbaImage::from_raw(width, height, img.rgba().to_vec())
                .ok_or_else(|| OcrErrorDto::internal("解析图像像素矩阵失败"))?;
            let resized = image::imageops::resize(
                &dyn_img,
                nw,
                nh,
                image::imageops::FilterType::Triangle,
            );
            resized.into_raw()
        } else {
            img.rgba().to_vec()
        };

        // 3. RGBA 转 BGRA8 并装载 SoftwareBitmap
        let bgra_bytes = rgba_to_bgra(&rgba_bytes);
        
        use windows::Graphics::Imaging::{BitmapAlphaMode, BitmapPixelFormat, SoftwareBitmap};
        use windows::Storage::Streams::DataWriter;

        let writer = DataWriter::new()
            .map_err(|e| OcrErrorDto::internal(format!("初始化 DataWriter 失败: {e}")))?;
        writer.WriteBytes(&bgra_bytes)
            .map_err(|e| OcrErrorDto::internal(format!("写入图像像素失败: {e}")))?;
        let buffer = writer.DetachBuffer()
            .map_err(|e| OcrErrorDto::internal(format!("分离 Buffer 失败: {e}")))?;

        let bitmap = SoftwareBitmap::CreateCopyFromBuffer(
            &buffer,
            BitmapPixelFormat::Bgra8,
            nw as i32,
            nh as i32,
            BitmapAlphaMode::Premultiplied,
        ).map_err(|e| OcrErrorDto::internal(format!("创建 SoftwareBitmap 失败: {e}")))?;

        // 4. 构建去重语言列表并轮询执行识别
        let candidates = build_candidate_languages(&target_lang);
        use windows::Globalization::Language;
        use windows::Media::Ocr::OcrEngine;

        let mut all_engines_missing = true;

        for cand in candidates {
            let engine_res = if cand == "system" {
                OcrEngine::TryCreateFromUserProfileLanguages()
            } else {
                match Language::CreateLanguage(&windows::core::HSTRING::from(cand)) {
                    Ok(l) => OcrEngine::TryCreateFromLanguage(&l),
                    Err(_) => continue,
                }
            };

            let Ok(engine) = engine_res else {
                continue;
            };
            all_engines_missing = false;

            let recognize_op = match engine.RecognizeAsync(&bitmap) {
                Ok(op) => op,
                Err(_) => continue,
            };

            if let Ok(ocr_result) = recognize_op.get() {
                if let Ok(hstr) = ocr_result.Text() {
                    let text = hstr.to_string();
                    if !text.trim().is_empty() {
                        return Ok(text.trim().to_string());
                    }
                }
            }
        }

        if all_engines_missing {
            Err(OcrErrorDto::no_language_pack())
        } else {
            Err(OcrErrorDto::empty_text())
        }
    })
    .await
    .map_err(|e| OcrErrorDto::internal(format!("异步任务调度异常: {e}")))?
}
```
