# extension (浏览器扩展)

> 基于 Manifest V3 的 Transly 沉浸式整页翻译插件。

[![standard-readme compliant](https://img.shields.io/badge/readme%20style-standard-brightgreen.svg?style=flat-square)](https://github.com/RichardLitt/standard-readme)

本插件是与桌面端同等地位的一等公民，**核心定位是“整页翻译仅译文”**——极简、低干扰、高保真。类似原生浏览器翻译，用目标语言译文原地直接替换网页原始文本（仅译文模式），绝不做破坏排版的双语混排、不堆砌词典与花哨分析。

## 架构原则

1. **瘦客户端**：插件端**不存 API 密钥**，**不直连外网翻译接口**。
2. **本地协作**：所有翻译请求通过本地回环地址（`127.0.0.1:39281`）路由至 Transly 桌面端处理，共享凭据与 SQLite 缓存。

## 关键技术

- **原地 DOM 替换**：精确定位文本节点直接替换，保留原有 CSS 样式与页面排版，并记录原始文本属性支持一键无损还原。
- **批量合并翻译 (Batch Translation)**：聚合正文文本块，按项数与字符总量双上限切批后交由桌面端处理，避免碎片化网络请求。切批契约由服务端 `/health` 动态提供，两端同源。
- **视口感知优先切批 (Viewport-First)**：先期计算 DOM 节点几何视口，将当前屏幕可视文本优先切批外呼，离屏段落保序排队，数百毫秒内即可呈现首屏译文。
- **开放式 Shadow DOM 穿透**：流式 TreeWalker 遍历递归下探开放模式（`open`）ShadowRoot，完整提取并翻译现代 Web Components 组件文本。
- **富文本段落行内标签保真**：对包含 `<a>`、`<code>`、`<strong>` 等行内标签的段落，整句使用占位符保护翻译，并基于显式 `isInline` 属性安全拓扑回填，杜绝跨语种倒装破版。
- **双语对照与仅译文双模式**：支持沉浸式仅译文模式（原地替换）与双语对照模式（追加隔离兄弟译文节点）一键切换。
- **增量监听 (MutationObserver)**：自适应 SPA 页面动态加载与瀑布流内容，并在还原时彻底注销释放。
- **主动注入（非常驻）**：不声明 `content_scripts` 常驻注入，不申请全网宿主权限。仅在用户点击「翻译此网页」或首次触发划词时通过 `chrome.scripting.executeScript` 按需注入。
- **划词微型悬浮图标与气泡**：选中文本后光标旁悬浮微型 Transly 图标，一键展开气泡；或使用右键菜单「Transly 翻译选中文本」。气泡与图标均渲染在封闭式 Shadow DOM（`mode: 'closed'`）中，与宿主页面样式脚本完全隔离。
- **悬浮查看原文 Tooltip**：原地仅译文替换后，鼠标悬停于译文段落上方，自动通过轻量 Shadow DOM 浮层展示原始文本。
- **终态广播一次**：任务级终态（完成 / 部分失败 / 失败）由首屏任务、重试或增量批次组在单组结束后广播一次，不在批次函数内广播，防止动态增量监听导致徽标持续闪烁。

## 构建与调试

```sh
cd extension
pnpm build
```

产物输出到 `extension/dist`：`manifest.json`、`popup.html` 与 `_locales/` 由 `scripts/postbuild.mjs` 复制。

### 文案国际化

所有 UI 文案存放在 `_locales/zh_CN|en/messages.json`（Chrome 原生 i18n），代码与 HTML 只用 `t()` 或 `data-i18n*` 引用，禁止硬编码文案；`manifest.json` 的名称与描述通过 `__MSG_*__` 引用，随浏览器语言自动切换。

在 Chrome 或 Edge 扩展管理界面中开启开发者模式，点击“加载已解压的扩展程序”，选择 `extension/dist` 即可。

### 详细操作步骤

1. **一键自动配对流程（推荐）**：
   - 打开浏览器扩展 Popup，点击【一键配对桌面端】。
   - 桌面端主窗口自动唤起并弹出配对授权卡片，点击【允许配对】即可自动握手写入 Token，状态即刻变为“● 已连接且配对有效”。
   - （备用手动方式）：在 Transly 桌面端设置中复制“扩展配对 Token”，在扩展弹窗中粘贴并点击“保存配对 Token”。
2. **整页沉浸式翻译**：
   - 浏览任意非中文网页，点击“翻译此网页 (仅译文)”，正文原地无损替换为译文；或切换至“双语对照”模式。
   - 可在弹窗底栏勾选「为此站点记住自动翻译」，下次访问该网站将自动翻译。
3. **还原原文**：
   - 点击扩展弹窗中的“还原原文”，页面瞬间恢复原始英文，双语对照节点自动彻底清理。
4. **Token 动态轮换处理**：
   - 若桌面端重新生成了 Token，扩展会即时识别并在弹窗提示“▲ Token 已失效，请重新配对 (401)”。
   - 重新点击一键配对或粘贴新 Token 即可恢复通信。
5. **划词翻译**：
   - 在任意网页选中文本，光标右上角自动浮现微型 Transly 图标，点击直接展开译文气泡；亦可右键选择「Transly 翻译选中文本」。
   - 气泡中点击「复制」快速复制译文，按 `Esc` 或点击外部关闭。
