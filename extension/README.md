# extension (浏览器扩展)

> 基于 Manifest V3 的 Transly 沉浸式整页翻译插件。

[![standard-readme compliant](https://img.shields.io/badge/readme%20style-standard-brightgreen.svg?style=flat-square)](https://github.com/RichardLitt/standard-readme)

本插件是与桌面端同等地位的一等公民，**核心定位是“整页翻译仅译文”**——极简、低干扰、高保真。类似原生浏览器翻译，用目标语言译文原地直接替换网页原始文本（仅译文模式），绝不做破坏排版的双语混排、不堆砌词典与花哨分析。

## 架构原则

1. **瘦客户端**：插件端**不存 API 密钥**，**不直连外网翻译接口**。
2. **本地协作**：所有翻译请求通过本地回环地址（`127.0.0.1:39281`）路由至 Transly 桌面端处理，共享凭据与 SQLite 缓存。

## 关键技术

- **原地 DOM 替换**：精确定位文本节点直接替换，保留原有 CSS 样式与页面排版，并记录原始文本属性支持一键无损还原。
- **批量合并翻译 (Batch Translation)**：按可视区域文本块聚合，批量交由桌面端处理，避免碎片化网络请求。
- **增量监听 (MutationObserver)**：自适应 SPA 页面动态加载与瀑布流内容。
- **主动注入（非常驻）**：不声明 `content_scripts` 常驻注入，也不申请 `<all_urls>` 宿主权限。仅在用户点击「翻译此网页」时通过 `chrome.scripting.executeScript` 注入，与 `PRIVACY_POLICY.md` 的「仅在主动触发时提取 DOM 文本」承诺一致。
- **终态广播一次**：任务级终态（完成 / 部分失败 / 失败）由首屏任务、重试或增量批次组在单组结束后广播一次，不在批次函数内广播，否则动态增量监听会导致徽标持续闪烁。

## 构建与调试

```sh
cd extension
pnpm build
```

在 Chrome 或 Edge 扩展管理界面中开启开发者模式，点击“加载已解压的扩展程序”，选择 `extension/dist` 即可。

### 详细操作步骤

1. **配对流程**：
   - 在 Transly 桌面端主界面设置中复制“扩展配对 Token”。
   - 点击浏览器扩展图标，在输入框粘贴 Token 并点击“保存配对 Token”。
   - 确认状态显示为绿色“● 已连接且配对有效”。
2. **整页翻译**：
   - 浏览任意非中文网页，点击“翻译此网页 (仅译文)”。
   - 网页所有可视正文将原地无损替换为中文译文，样式排版完全保真。
3. **还原原文**：
   - 点击扩展弹窗中的“还原原文”，页面瞬间恢复原始英文。
4. **Token 动态轮换处理**：
   - 若桌面端重新生成了 Token，扩展会即时识别并在弹窗提示“▲ Token 已失效，请重新配对 (401)”。
   - 重新粘贴新 Token 保存即可立即恢复通信。
